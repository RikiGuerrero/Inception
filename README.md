## 📌 Descripción  
**Inception** es un proyecto desarrollado como parte del currículo de la escuela 42. Su objetivo principal es configurar un entorno de desarrollo web completamente funcional utilizando contenedores Docker. Este proyecto permite a los estudiantes adquirir experiencia práctica en la contenedorización de servicios, la gestión de redes, volúmenes, certificados TLS y la administración de sistemas web modernos.

## ⚙️ Servicios Implementados  
- **NGINX**: servidor web con soporte para HTTPS mediante certificados TLS autofirmados.  
- **WordPress**: plataforma CMS alojada en un contenedor independiente.  
- **MariaDB**: base de datos relacional que gestiona los datos de WordPress.  
- **Redis**: sistema de caché para mejorar el rendimiento del sitio.  
- **FTP**: servidor FTP seguro para subir archivos al contenedor WordPress.  
- **Adminer**: herramienta web para gestionar bases de datos MariaDB.  
- **Netdata**: solución de monitorización en tiempo real del sistema y contenedores.

## 🛠 Lenguajes y Tecnologías  
- **Lenguajes**: Bash, Dockerfile, YAML  
- **Contenedores**: Docker  
- **Orquestación**: Docker Compose  
- **Seguridad**: Certificados TLS, usuarios y permisos  
- **Sistemas**: Linux, administración de servicios

## 💡 Conceptos de Programación y DevOps  
- Contenedorización con Docker  
- Orquestación de múltiples servicios con Docker Compose  
- Redes y volúmenes en Docker  
- Configuración de servicios web y base de datos  
- Seguridad en servicios (TLS, permisos, usuarios)  
- Monitorización y mantenimiento de servidores
